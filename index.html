1. Ground-Truth Anchoring (Eliminating Math Hallucinations)

LLMs frequently make arithmetic errors with multi-step budgeting. By computing totals in deterministic JavaScript and passing them as immutable facts, the prompt instructs the model to adhere strictly to the ground-truth figures.

2. Role-Based Prompting & Boundary Setting

The prompt explicitly instructs the agent to act as an educational budgeting coach, requiring structured headings, simple English, and explicit disclaimers without making risky financial promises.

3. Feasibility Branching & Decision Tree Guidance

The prompt enforces distinct analysis paths for three scenarios: Achievable, Shortfall, and Deficit, preventing optimistic hallucinations when money runs short.

4. Transparent Category Classification

Expenses are segregated into Essential (Needs) and Non-Essential (Wants), allowing targeted recommendations on discretionary spending while safeguarding necessities.
